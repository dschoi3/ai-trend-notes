# AI Trend Notes

평일 아침마다 AI 분야 소식을 모아 자동으로 요약한 Daily Report 모음이다.

> [!WARNING]
> 모든 노트는 LLM(Claude)이 사람의 검수 없이 자동으로 작성했다.
> 요약마다 원문 근거를 검증하는 단계를 거치지만, 요약과 해석은 틀릴 수 있다.
> 인용하거나 판단에 쓰기 전에 각 항목의 원문 링크를 확인한다.

- `reports/YYYY/YYYY-MM-DD.md`: 날짜별 Daily Report
- `Topics.md`: 여러 날의 Daily Report를 잇는 Topic 목록
- 출처: 직접 고른 블로그 RSS, Hacker News, Hugging Face Daily Papers, GitHub Trending.
  각 글의 저작권은 원저자에게 있으며, 이 저장소는 제목·링크·짧은 요약만 싣는다.

이 저장소는 봇이 관리한다. 이 README도 실행할 때마다 다시 쓴다.
